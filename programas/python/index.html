Python inicial comienza desde los fundamentos. Para el avanzado se verifican los conocimientos previos.

Una computadora con teclado y conexión estable a internet. Se recomienda mouse y cámara.

Puede reforzar la lógica, el razonamiento matemático y la resolución de problemas. No reemplaza el currículo escolar.
