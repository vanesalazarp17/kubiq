Preguntas frecuentes

Información práctica para que puedas decidir con tranquilidad.

¿Necesita saber programar?

No para Scratch inicial. Para Scratch avanzado se revisan los conocimientos previos antes de confirmar el nivel.

¿Qué necesita para las clases?

Una computadora con conexión estable a internet. Se recomienda usar mouse y mantener la cámara disponible durante la clase.

¿Qué puede crear?

Historias animadas, escenas interactivas y videojuegos con personajes, reglas y sonidos.
